# 90-second Authority Gate Demo

1. Open with: "Access does not equal authority."
2. Show a supplier payment-change request arriving through a trusted-looking channel.
3. Explain that AI can extract the request, but cannot authorise it.
4. Leave Authority unchecked and run the gate. Show BLOCKED.
5. Try APPROVE while the gate is failed. Show that execution remains blocked.
6. Mark identity, authority, permission and scope as verified evidence for the demo, with risk set to REVIEW or LOW.
7. Run the gate again. Show READY_FOR_HUMAN_REVIEW.
8. Explain that passing verification still does not execute automatically.
9. Human selects APPROVE. If Sandbox credentials are configured, show the PayPal Sandbox order ID.
10. Show the audit ID and evidence fingerprint.
11. Close with: "AI investigates. Humans decide. Evidence proves what happened."

Important: say clearly that checkbox controls are demo inputs. Production verification must use authoritative independent evidence.
